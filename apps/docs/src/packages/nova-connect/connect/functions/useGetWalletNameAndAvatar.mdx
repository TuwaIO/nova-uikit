# useGetWalletNameAndAvatar()

> **useGetWalletNameAndAvatar**(`options`): [`WalletNameAndAvatarData`](?path=/docs/packages-nova-connect-connect-interfaces-walletnameandavatardata--docs)

Defined in: [packages/nova-connect/src/hooks/useGetWalletNameAndAvatar.ts:105](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-connect/src/hooks/useGetWalletNameAndAvatar.ts#L105)

Resolves the name (ENS on EVM, SNS on Solana) and its avatar for the active wallet with `getName` and `getAvatar`
of its Satellite adapter, which ask a name service only when the adapter was created with the option for it (by
default an EVM name is read over the mainnet RPC, no avatar is looked up, and a Solana name is the address with an
identicon drawn locally). All the callers share one lookup per wallet, kept
for the life of the page; a failed one is not kept. It reads again when the address or the adapter changes, and drops
the previous answer. Without a name it returns the shortened address.

## Example

```tsx
import { useGetWalletNameAndAvatar } from '@tuwaio/nova-connect/hooks';

export function WalletInfo() {
  const { ensAvatar, ensNameAbbreviated, isLoading, error, retry } = useGetWalletNameAndAvatar({});

  if (isLoading) return <p>Resolving name...</p>;
  if (error) return <button onClick={retry}>Retry</button>;

  return (
    <p>
      {ensAvatar && <img src={ensAvatar} alt="" width={24} height={24} />}
      {ensNameAbbreviated}
    </p>
  );
}
```
