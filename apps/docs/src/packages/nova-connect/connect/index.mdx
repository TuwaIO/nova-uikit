# connect

The providers, the SIWX watcher, the chain configuration types and the chain helpers of Nova Connect, imported from
`@tuwaio/nova-connect`. This entry point imports no EVM or Solana package: import `@tuwaio/nova-connect/evm` and
`@tuwaio/nova-connect/solana` for the networks of your app.
