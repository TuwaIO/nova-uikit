# NovaConnectChainConfigTypes

Defined in: [packages/nova-connect/src/types.ts:8](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-connect/src/types.ts#L8)

Chain configuration types of the networks the app imports. Importing `@tuwaio/nova-connect/evm` adds `appChains`
(the viem chains of your wagmi config, `readonly [Chain, ...Chain[]]`); importing `@tuwaio/nova-connect/solana` adds
`solanaRPCUrls` (`Partial<Record<SolanaClusterMoniker, string>>` from `@tuwaio/orbit-solana`). Read the resulting
types through [NovaConnectAppChains](?path=/docs/packages-nova-connect-connect-type-aliases-novaconnectappchains--docs) and [NovaConnectSolanaRPCUrls](?path=/docs/packages-nova-connect-connect-type-aliases-novaconnectsolanarpcurls--docs).
