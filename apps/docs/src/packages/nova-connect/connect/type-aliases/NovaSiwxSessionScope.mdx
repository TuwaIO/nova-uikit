# NovaSiwxSessionScope

> **NovaSiwxSessionScope** = `"chain"` \| `"account"`

Defined in: [packages/nova-connect/src/watchers/NovaSiwxWatcher.tsx:17](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-connect/src/watchers/NovaSiwxWatcher.tsx#L17)

What a SIWX session belongs to: `'chain'`, the account on the chain it was signed on, or `'account'`, the account on
every chain of its namespace (an EVM address on every EVM chain, a Solana address on every cluster).
