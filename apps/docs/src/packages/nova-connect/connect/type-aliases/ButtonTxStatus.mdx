# ButtonTxStatus

> **ButtonTxStatus** = `"idle"` \| `"loading"` \| `"succeed"` \| `"failed"` \| `"replaced"` \| `"cancelled"`

Defined in: [packages/nova-connect/src/hooks/useNovaConnect.ts:15](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-connect/src/hooks/useNovaConnect.ts#L15)

What the connect button shows about the transactions of the wallet: `idle`, `loading` while one is pending, and for a moment
after a transaction ends, `succeed`, `failed`, `cancelled` or `replaced`. A speed-up is no result: it stays `loading`.
