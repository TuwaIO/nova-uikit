# Connecting

> `const` **Connecting**: `NamedExoticComponent`\<[`ConnectingProps`](?path=/docs/packages-nova-connect-components-interfaces-connectingprops--docs) & `RefAttributes`\<`HTMLDivElement`\>\>

Defined in: [packages/nova-connect/src/components/ConnectModal/Connecting.tsx:558](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-connect/src/components/ConnectModal/Connecting.tsx#L558)

The connection screen of the connect modal: the wallet icon in a circle with a spinner while connecting, a success
or error icon, the heading and, on error, a message. Reads `connectionError` from the Satellite store.

Props: [ConnectingProps](?path=/docs/packages-nova-connect-components-interfaces-connectingprops--docs); the ref is forwarded to the container.

## Example

```tsx
import { getFilteredConnectors } from '@tuwaio/nova-connect';
import { Connecting } from '@tuwaio/nova-connect/components';
import { useWalletConnectors } from '@tuwaio/nova-connect/hooks';
import { OrbitAdapter } from '@tuwaio/orbit-core';

export function MetaMaskStatus({ isConnected }: { isConnected: boolean }) {
  const connectors = getFilteredConnectors({
    connectors: useWalletConnectors() ?? {},
    selectedAdapter: OrbitAdapter.EVM,
  });

  return (
    <Connecting
      activeConnector="metamask"
      selectedAdapter={OrbitAdapter.EVM}
      connectors={connectors}
      isConnected={isConnected}
    />
  );
}
```
