# GetWallet

> `const` **GetWallet**: `ForwardRefExoticComponent`\<[`GetWalletProps`](?path=/docs/packages-nova-connect-components-interfaces-getwalletprops--docs) & `RefAttributes`\<`HTMLElement`\>\>

The "Get a wallet" screen of the connect modal: floating icons of popular wallets (MetaMask, Coinbase, Trust, Rabby,
Phantom by default) over a stars background, a title and a description from the Nova Connect labels.

Props: [GetWalletProps](?path=/docs/packages-nova-connect-components-interfaces-getwalletprops--docs); the ref is forwarded to the container.
