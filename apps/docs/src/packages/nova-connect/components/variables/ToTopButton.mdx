# ToTopButton

> `const` **ToTopButton**: `ForwardRefExoticComponent`\<[`ToTopButtonProps`](?path=/docs/packages-nova-connect-components-interfaces-totopbuttonprops--docs) & `RefAttributes`\<`HTMLButtonElement`\>\>

Defined in: [packages/nova-connect/src/components/ToTopButton.tsx:152](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-connect/src/components/ToTopButton.tsx#L152)

A full-width button with a chevron pointing up, which the scrollable lists of Nova Connect (such as the chain list)
show to scroll to the top. The scrolling is done by `onClick`; the button calls it on click and on Enter or Space.
Its label defaults to the `scrollToTop` label (overridable with `aria-label`).

Props: [ToTopButtonProps](?path=/docs/packages-nova-connect-components-interfaces-totopbuttonprops--docs); the ref is forwarded to the button.
