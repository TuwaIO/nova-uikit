# ToBottomButton

> `const` **ToBottomButton**: `ForwardRefExoticComponent`\<[`ToBottomButtonProps`](?path=/docs/packages-nova-connect-components-interfaces-tobottombuttonprops--docs) & `RefAttributes`\<`HTMLButtonElement`\>\>

Defined in: [packages/nova-connect/src/components/ToBottomButton.tsx:155](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-connect/src/components/ToBottomButton.tsx#L155)

A full-width button with a chevron pointing down, which the scrollable lists of Nova Connect (such as the chain list)
show to scroll to the bottom. The scrolling is done by `onClick`; the button calls it on click and on Enter or Space.
Its label defaults to the `scrollToBottom` label (overridable with `aria-label`).

Props: [ToBottomButtonProps](?path=/docs/packages-nova-connect-components-interfaces-tobottombuttonprops--docs); the ref is forwarded to the button.
