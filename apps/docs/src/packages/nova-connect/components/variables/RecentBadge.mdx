# RecentBadge

> `const` **RecentBadge**: `NamedExoticComponent`\<[`RecentBadgeProps`](?path=/docs/packages-nova-connect-components-interfaces-recentbadgeprops--docs) & `RefAttributes`\<`HTMLSpanElement`\>\>

Defined in: [packages/nova-connect/src/components/ConnectModal/RecentBadge.tsx:310](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-connect/src/components/ConnectModal/RecentBadge.tsx#L310)

The "Recent" badge of a wallet card: a square chip in the accent, its label in monospace capitals, with a still frame
of 1 px. With `animated` (or `config.animated`), a light runs along the frame (Framer Motion). It is smaller on touch
devices.

Props: [RecentBadgeProps](?path=/docs/packages-nova-connect-components-interfaces-recentbadgeprops--docs); the ref is forwarded to the container.

## Example

```tsx
import { RecentBadge } from '@tuwaio/nova-connect/components';

export const Badge = (
  <RecentBadge
    customization={{
      config: {
        animated: true,
        animation: { duration: 2, ease: 'easeInOut' },
        gradient: {
          direction: '45deg',
          stops: [
            { position: 0, color: 'transparent' },
            { position: 50, color: 'rgba(59, 130, 246, 0.8)' },
            { position: 100, color: 'transparent' },
          ],
        },
      },
    }}
  >
    Last used
  </RecentBadge>
);
```
