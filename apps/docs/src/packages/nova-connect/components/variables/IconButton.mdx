# IconButton

> `const` **IconButton**: `ForwardRefExoticComponent`\<[`IconButtonProps`](?path=/docs/packages-nova-connect-components-interfaces-iconbuttonprops--docs) & `RefAttributes`\<`Omit`\<`HTMLButtonElement`, `"style"`\>\>\>

Defined in: [packages/nova-connect/src/components/ConnectedModal/IconButton.tsx:439](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-connect/src/components/ConnectedModal/IconButton.tsx#L439)

A round button with a wallet icon and/or a network icon, used by the connected modal to open the connections and
network screens. It is clickable, with a chevron, only when `onClick` is set and `items` is above 1.

Props: [IconButtonProps](?path=/docs/packages-nova-connect-components-interfaces-iconbuttonprops--docs); the ref is forwarded to the button.

## Example

```tsx
import { IconButton } from '@tuwaio/nova-connect/components';

export const NetworkButton = (
  <IconButton
    walletChainId="devnet"
    items={3}
    onClick={() => console.log('open the network list')}
    customization={{
      classNames: {
        chevronContainer: ({ isOpen }) => (isOpen ? 'chevron-open' : 'chevron-closed'),
      },
      animation: { button: { duration: 0.3, ease: 'easeOut' } },
    }}
  />
);
```
