#### buttonTestId?

#### chainIdFormatter?

> `optional` **chainIdFormatter?**: (`chainId`) => `string` \| `number`

Formats `walletChainId` for the network icon, instead of the default (a string becomes its Solana CAIP-2 chain ID
with the genesis hash, e.g. `devnet` → `solana:EtWTRABZaYq6iMfeYKouRu166VU2xqa1`).

##### Parameters

###### chainId

`string` \| `number`

The `walletChainId` prop.

##### Returns

`string` \| `number`

The chain ID for `NetworkIcon` of `@tuwaio/nova-core`.

#### disableAnimation?

> `optional` **disableAnimation?**: `boolean`

Renders a plain button without Framer Motion (default: `false`)

#### reduceMotion?

> `optional` **reduceMotion?**: `boolean`

Same as `disableAnimation` (default: `false`)

#### showChainIcon?

> `optional` **showChainIcon?**: `boolean`

Whether to show the chain icon when `walletChainId` is set (default: `true`)

#### showChevron?

> `optional` **showChevron?**: `boolean`

Whether to show the chevron on a clickable button (default: `true`)

#### showLoadingOverlay?

> `optional` **showLoadingOverlay?**: `boolean`

Whether to render the loading overlay (default: `true`)

#### showWalletIcon?

> `optional` **showWalletIcon?**: `boolean`
