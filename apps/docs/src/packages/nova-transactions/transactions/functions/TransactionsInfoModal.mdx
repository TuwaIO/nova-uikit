# TransactionsInfoModal()

> **TransactionsInfoModal**\<`T`\>(`props`): `Element`

Defined in: [components/TransactionsInfoModal.tsx:141](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-transactions/src/components/TransactionsInfoModal.tsx#L141)

A modal with the transaction history of the connected wallet ([TransactionsHistory](?path=/docs/packages-nova-transactions-transactions-functions-transactionshistory--docs)) and the details of a
transaction ([TransactionDetails](?path=/docs/packages-nova-transactions-transactions-functions-transactiondetails--docs)): selecting a transaction in the list, or opening the modal with
`selectedTxKey`, shows its details under the same header, which then has a back button and the title of the details.
The modal opens on the list again after it is closed. Only transactions of `connectedWalletAddress` are shown.
`NovaTransactionsProvider` opens it from the toasts and the tracking modal.
