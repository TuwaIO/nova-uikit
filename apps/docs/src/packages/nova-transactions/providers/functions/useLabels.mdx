# useLabels()

> **useLabels**(): [`NovaTransactionsLabels`](?path=/docs/packages-nova-transactions-transactions-type-aliases-novatransactionslabels--docs)

Defined in: [providers/NovaTransactionsLabelsProvider.tsx:85](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-transactions/src/providers/NovaTransactionsLabelsProvider.tsx#L85)

A custom hook to easily access the i18n labels from any component: those of the `NovaTransactionsLabelsProvider`
above it, otherwise those of the `NovaTransactionsProvider` mounted in the app, otherwise the English defaults.

## Returns

[`NovaTransactionsLabels`](?path=/docs/packages-nova-transactions-transactions-type-aliases-novatransactionslabels--docs)

The complete object of UI labels.

## Example

```ts
const MyComponent = () => {
const labels = useLabels();
return <h1>{labels.walletModal.title}</h1>;
}
```
