# XIcon

The mark of X (formerly Twitter), drawn in pixels; not a close mark, which is `XMarkIcon`. A Nova icon on a 16 × 16 pixel grid, in `@tuwaio/nova-icons/brands` and the main entry, for a link to the service; the mark belongs to its owner.

## Param

**props**

The props of the SVG element, `title` to name it for a screen reader, `motion` to play a motion once
(`NovaIconProps`).
