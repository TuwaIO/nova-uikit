# shortAddress()

> **shortAddress**(`address`, `head?`, `tail?`): `string`

Defined in: [utils/format.ts:65](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-payments/src/utils/format.ts#L65)

An address shortened to its start and end, as wallets show it.

## Parameters

### address

`string`

The address (`0x…` or base58).

### head?

`number` = `...`

Characters kept at the start; `0x` counts toward it (default `6` for `0x`, `4` otherwise).

### tail?

`number` = `4`

Characters kept at the end (default `4`).

## Returns

`string`

For example `0x1111…2222`; a short address unchanged.
