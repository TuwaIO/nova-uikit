# canPayWithQr()

> **canPayWithQr**(`method`, `payUrl?`): `boolean`

Defined in: [utils/methods.ts:122](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-payments/src/utils/methods.ts#L122)

Whether a method can be paid by scanning a QR code with a phone: Solana with Solana Pay, an EVM method only through
the payment page opened on the phone.

## Parameters

### method

`CheckoutMethod`

The method.

### payUrl?

`string` \| `null`

The payment page of the invoice (its `payUrl`), if the app has it.

## Returns

`boolean`

Whether the QR option applies.
