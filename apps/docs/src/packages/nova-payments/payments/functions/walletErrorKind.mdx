# walletErrorKind()

Why a wallet request failed, from the error the wallet library threw: EIP-1193 code `4001` and viem's
`UserRejectedRequestError` (also as a `cause`), and the "user rejected" messages of Wallet Standard wallets, are
`declined`.

## Parameters

### error

`unknown`

What the wallet library threw.

## Returns

[`PaymentWalletErrorKind`](?path=/docs/packages-nova-payments-payments-type-aliases-paymentwalleterrorkind--docs)

`declined`, `unsupported`, `wrongNetwork` or `failed`.
