# unconfirmedTxKey()

> **unconfirmedTxKey**(`state`, `checkout`): `string` \| `null`

Defined in: [utils/checkout.ts:581](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-payments/src/utils/checkout.ts#L581)

The transaction the buyer names to the seller about a payment Quasar did not confirm: the one this page handed over
(`txHash`, else `txKey` of the checkout store), else, on a reopened page, the newest one Quasar rejected.

## Parameters

### state

`Pick`\<`CheckoutState`, `"txKey"` \| `"txHash"`\>

### checkout

`CheckoutView` \| `null`

What the checkout token opens; `null` until loaded.

## Returns

`string` \| `null`

The transaction hash (EVM) or signature (Solana), or `null` when the page does not know it.
