# useAutoReturn()

> **useAutoReturn**(`params`): `object`

Defined in: [hooks/useOutcomeEffects.ts:51](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-payments/src/hooks/useOutcomeEffects.ts#L51)

The visible countdown before the paid outcome sends the buyer back to the seller, with "Stay here" (WCAG 2.2.1).

Side effects: navigates the page when the countdown ends.
