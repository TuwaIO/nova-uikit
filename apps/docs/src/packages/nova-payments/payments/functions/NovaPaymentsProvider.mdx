# NovaPaymentsProvider()

> **NovaPaymentsProvider**(`props`): `Element`

Defined in: [providers/NovaPaymentsProvider.tsx:67](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-payments/src/providers/NovaPaymentsProvider.tsx#L67)

Gives the checkouts below it the Quasar API, the labels and the chain adapters. A checkout works without it, with
Quasar Cloud, the built-in labels and QR payments only.

## Parameters

### props

[`NovaPaymentsProviderProps`](?path=/docs/packages-nova-payments-payments-interfaces-novapaymentsproviderprops--docs)

See [NovaPaymentsProviderProps](?path=/docs/packages-nova-payments-payments-interfaces-novapaymentsproviderprops--docs).

## Returns

`Element`

The provider.

## Example

```tsx
import { NovaPaymentsProvider, PaymentCheckout } from '@tuwaio/nova-payments';

export function Checkout({ token }: { token: string }) {
  return (
    <NovaPaymentsProvider baseUrl="https://quasar.example.com" labels={{ steps: { pay: 'Payment' } }}>
      <PaymentCheckout token={token} display="inline" />
    </NovaPaymentsProvider>
  );
}
```
