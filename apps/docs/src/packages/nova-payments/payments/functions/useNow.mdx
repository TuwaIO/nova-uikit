# useNow()

> **useNow**(`intervalMs`, `active?`): `number`

Defined in: [hooks/useNow.ts:12](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-payments/src/hooks/useNow.ts#L12)

The current time, updated every `intervalMs` while `active`.

Side effect: an interval timer while active.

## Parameters

### intervalMs

`number`

How often to update, in milliseconds.

### active?

`boolean` = `true`

Whether to update (stop on a final state to save renders).

## Returns

`number`

`Date.now()` of the latest update.
