# balanceShortfall()

> **balanceShortfall**(`balance`, `quote`, `fee?`): [`BalanceShortfall`](?path=/docs/packages-nova-payments-payments-interfaces-balanceshortfall--docs) \| `null`

Defined in: [utils/pay.ts:104](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-payments/src/utils/pay.ts#L104)

What a wallet lacks to pay a quote.

## Parameters

### balance

`bigint`

The wallet's balance of the quoted token, in base units.

### quote

`CheckoutQuote`

The locked quote.

### fee?

`bigint` = `0n`

The network fee, when it is paid in the quoted token (the native coin); counted in what is needed.

## Returns

[`BalanceShortfall`](?path=/docs/packages-nova-payments-payments-interfaces-balanceshortfall--docs) \| `null`

The shortfall, or `null` when the balance is enough.
