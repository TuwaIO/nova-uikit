# quoteRate()

> **quoteRate**(`quote`, `totalMinor`): `number` \| `null`

Defined in: [utils/pay.ts:73](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-payments/src/utils/pay.ts#L73)

The market price of one token in the invoice currency behind a quote. Quasar asks for
`total × (1 + markup) × (1 − discount) / price` tokens, so the price is recovered without the method's markup or
discount, which the checkout shows apart. For display only: amounts are never derived from it.

## Parameters

### quote

`CheckoutQuote`

The locked quote.

### totalMinor

`string` \| `null`

The invoice total in minor units (cents) the quote pays.

## Returns

`number` \| `null`

The price, or `null` without a total or a token amount.
