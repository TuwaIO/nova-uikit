# baseUnitsToDecimal()

> **baseUnitsToDecimal**(`baseUnits`, `decimals`): `string`

Defined in: [utils/format.ts:64](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-payments/src/utils/format.ts#L64)

A token amount as a wallet takes it when pasted: exact, with a dot, without grouping or trailing zeros.

## Parameters

### baseUnits

`string`

Base units, as a decimal integer string (not negative).

### decimals

`number`

Decimals of the token.

## Returns

`string`

For example `89.54` for `89540000` with 6 decimals, `5` for `5000000`.
