# groupMethodsByToken()

> **groupMethodsByToken**(`methods`, `walletChainId?`): [`CheckoutTokenGroup`](?path=/docs/packages-nova-payments-payments-interfaces-checkouttokengroup--docs)[]

Defined in: [utils/checkout.ts:142](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-payments/src/utils/checkout.ts#L142)

Groups payment methods by token: the token picked first, then its network (decision of 2026-10-10). Groups with a
method on the connected wallet's network come first, then those the merchant marks Popular; otherwise the
merchant's order stays.

## Parameters

### methods

`CheckoutMethod`[]

The methods of the checkout, in the merchant's order.

### walletChainId?

`string` \| `null`

CAIP-2 chain of the connected wallet, if any.

## Returns

[`CheckoutTokenGroup`](?path=/docs/packages-nova-payments-payments-interfaces-checkouttokengroup--docs)[]

The groups.
