The name of a method's network, from the chain names of `@tuwaio/nova-core`.

## Parameters

### chainId

`string`

CAIP-2 chain of the method (`eip155:8453`, `solana:EtWT…`).

## Returns

`string`

The name (`Base`, `Solana Devnet`), `Unknown` for a chain nova-core does not list.
