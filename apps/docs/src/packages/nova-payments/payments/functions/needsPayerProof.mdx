# needsPayerProof()

> **needsPayerProof**(`payerProof`, `path`): `boolean`

Defined in: [utils/payerProof.ts:39](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-payments/src/utils/payerProof.ts#L39)

Whether the wallet confirms the invoice before it pays from the pay step: while the checkout store says it must
(`required`, `confirming`), and for a method the gasless relay could pay (`unless_relayed`) when the wallet sends the
transfer or the paymaster's calls itself; the relay's signed authorization confirms the wallet on its own.

## Parameters

### payerProof

`string` \| `undefined`

`payerProof` of the checkout store (left out by older stores).

### path

[`PayPath`](?path=/docs/packages-nova-payments-payments-type-aliases-paypath--docs)

How the wallet pays the quote.

## Returns

`boolean`

`true` to ask for the confirmation first.
