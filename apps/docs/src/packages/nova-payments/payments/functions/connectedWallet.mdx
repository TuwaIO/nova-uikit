# connectedWallet()

> **connectedWallet**(`connection`, `connectors?`): [`CheckoutWallet`](?path=/docs/packages-nova-payments-payments-interfaces-checkoutwallet--docs) \| `null`

Defined in: [utils/methods.ts:120](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-payments/src/utils/methods.ts#L120)

The connected wallet of Satellite Connect in CAIP identifiers, named and shown as the wallet calls itself.

## Parameters

### connection

\{ `address`: `string`; `chainId`: `string` \| `number`; `connectorType`: `string`; `icon?`: `string`; \} \| `null` \| `undefined`

The active connection of the Satellite store: `address`, `chainId` (an EVM number or a Solana
cluster), `connectorType`, and the `icon` of the wallet when the adapter set it.

### connectors?

`Partial`\<`Record`\<`string`, `unknown`[]\>\>

The wallets of the Satellite store by adapter (`getConnectors()`): the one with the connector
type of the connection gives the name and the icon (see [walletLabel](?path=/docs/packages-nova-payments-payments-functions-walletlabel--docs)). Without it, or when it is not listed,
the name comes from the connector type and the icon from the connection.

## Returns

[`CheckoutWallet`](?path=/docs/packages-nova-payments-payments-interfaces-checkoutwallet--docs) \| `null`

The wallet, or `null` without a connection or with a chain the checkout cannot read.
