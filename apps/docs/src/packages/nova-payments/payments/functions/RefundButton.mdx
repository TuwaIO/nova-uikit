# RefundButton()

> **RefundButton**(`props`): `Element`

Defined in: [components/RefundButton.tsx:95](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-payments/src/components/RefundButton.tsx#L95)

A button that refunds a paid invoice from the merchant's connected wallet: it opens [RefundDialog](?path=/docs/packages-nova-payments-payments-functions-refunddialog--docs). Put it
inside `NovaPaymentsProvider` with the adapters of the chain families, and inside `NovaConnectProvider` to connect
the wallet.

## Parameters

### props

[`RefundButtonProps`](?path=/docs/packages-nova-payments-payments-interfaces-refundbuttonprops--docs)

See [RefundButtonProps](?path=/docs/packages-nova-payments-payments-interfaces-refundbuttonprops--docs).

## Returns

`Element`

The button and its window.

## Example

```tsx
import { createRefundStore } from '@tuwaio/quasar-sdk/checkout';
import { RefundButton } from '@tuwaio/nova-payments';

// refundInvoice, submitRefund and getRefund are Server Actions calling quasar.payments
const refunds = createRefundStore({ request: refundInvoice, submit: submitRefund, get: getRefund });

<RefundButton store={refunds} invoiceId={invoice.id} invoice={invoice.number} currency="USD" />;
```
