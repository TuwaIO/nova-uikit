# autoPayTerms()

The terms of an ERC-7715 automatic payments offer: the periodic limit in the token of the method, the period, the
expiry and the merchant's wallet the charges are paid to.

## Parameters

### offer

### methods

`CheckoutMethod`[]

The view's methods (for the token of the offer).

## Returns

[`AutoPayTerms`](?path=/docs/packages-nova-payments-payments-interfaces-autopayterms--docs) \| `null`
