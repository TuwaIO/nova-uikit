# solana

The Solana chain adapter of Nova Payments, imported from `@tuwaio/nova-payments/solana`: it pays Solana methods from
the Wallet Standard wallet connected through Satellite Connect. It needs `@solana/kit`, `@solana-program/system`,
`@solana-program/token` and `@tuwaio/orbit-solana`.
