# formatCountLabel()

> **formatCountLabel**(`forms`, `count`, `locale`, `values?`): `string`

Defined in: [i18n/formatLabel.ts:27](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-payments/src/i18n/formatLabel.ts#L27)

Fills a label that counts something, in the form the plural rule of the language picks for the count
(`Intl.PluralRules`): `one` for `1 item` (in Ukrainian and Russian also for 21, 31…), `other` for the rest. A
language tag that `Intl` does not accept takes the English rule.

## Parameters

### forms

The label for the `one` category and the label for every other count; both may use `{count}`.

#### one

`string`

The label when the rule picks `one`.

#### other

`string`

The label for any other count.

### count

`number`

The number counted, filled in as `{count}`.

### locale

`string`

The language of the label, a BCP 47 tag such as `uk` or `zh-CN`.

### values?

`Record`\<`string`, `string` \| `number`\> = `{}`

The other placeholders of the label.

## Returns

`string`

The label in the right form, with the values.
