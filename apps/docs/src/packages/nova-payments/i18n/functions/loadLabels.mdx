# loadLabels()

> **loadLabels**(`locale`): `Promise`\<[`NovaPaymentsLabels`](?path=/docs/packages-nova-payments-i18n-type-aliases-novapaymentslabels--docs)\>

Defined in: [i18n/locales.ts:65](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-payments/src/i18n/locales.ts#L65)

Loads the built-in labels of a language. Each language but English is a separate file that the page downloads the
first time it is asked for; the labels stay in memory for the page.

## Parameters

### locale

`string` \| `null` \| `undefined`

A language of the checkout; anything else gets English without loading anything.

## Returns

`Promise`\<[`NovaPaymentsLabels`](?path=/docs/packages-nova-payments-i18n-type-aliases-novapaymentslabels--docs)\>

The labels. A file that fails to load (the network dropped) leaves the language in English until the page
reloads.
