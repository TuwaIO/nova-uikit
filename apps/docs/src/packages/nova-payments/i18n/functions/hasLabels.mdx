# hasLabels()

> **hasLabels**(`locale`): `boolean`

Defined in: [i18n/locales.ts:42](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-payments/src/i18n/locales.ts#L42)

Whether the labels of a language are at hand: always for English and for a language the package does not have
(both get English), for the other languages of [CHECKOUT\_LOCALES](?path=/docs/packages-nova-payments-i18n-variables-checkout-locales--docs) once [loadLabels](?path=/docs/packages-nova-payments-i18n-functions-loadlabels--docs) has loaded them.

## Parameters

### locale

`string` \| `null` \| `undefined`

A language.

## Returns

`boolean`

`true` when [labelsForLocale](?path=/docs/packages-nova-payments-i18n-functions-labelsforlocale--docs) gives the labels of the language.
