# NovaIconsContext

> `const` **NovaIconsContext**: `Context`\<[`NovaIconSet`](?path=/docs/packages-nova-core-type-aliases-novaiconset--docs)\>

Defined in: [hooks/useNovaIcons.ts:137](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-core/src/hooks/useNovaIcons.ts#L137)

The icon set of the closest `NovaIconsProvider`, shared on `globalThis` so that two copies of this package agree.
Without a provider it is `pixelIcons`. It does not exist in a React Server Component, where React has no context.
