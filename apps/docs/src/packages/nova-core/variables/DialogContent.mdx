# DialogContent

> `const` **DialogContent**: `ForwardRefExoticComponent`\<`Omit`\<`DialogContentProps` & `RefAttributes`\<`HTMLDivElement`\>, `"ref"`\> & `object` & `RefAttributes`\<`HTMLDivElement`\>\>

Defined in: [components/Modal.tsx:102](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-core/src/components/Modal.tsx#L102)

The dialog panel (`Content` of `@radix-ui/react-dialog`), rendered in a portal above [DialogOverlay](?path=/docs/packages-nova-core-functions-dialogoverlay--docs). It takes
the props of the Radix `Content` plus `modalAnimation` and `backdropAnimation` (`framer-motion` variants). By default
the panel scales in at the center of the screen, or slides up from the bottom on touch devices (`isTouchDevice`); its
content scrolls when it is taller than the viewport. When it closes, the focus returns to the element that had it
when the dialog opened (Radix alone returns it only to a [DialogTrigger](?path=/docs/packages-nova-core-variables-dialogtrigger--docs)), unless `onCloseAutoFocus` prevents
that. Use it inside [Dialog](?path=/docs/packages-nova-core-variables-dialog--docs).
