# useNovaIcons()

> **useNovaIcons**(): [`NovaIconSet`](?path=/docs/packages-nova-core-type-aliases-novaiconset--docs)

Defined in: [hooks/useNovaIcons.ts:143](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-core/src/hooks/useNovaIcons.ts#L143)

Returns the icon set of the closest `NovaIconsProvider`: the icons the Nova components draw, and their look.

## Returns

[`NovaIconSet`](?path=/docs/packages-nova-core-type-aliases-novaiconset--docs)

The set; `pixelIcons` without a provider.

## Example

```tsx
import { useNovaIcons } from '@tuwaio/nova-core';

export function RetryLabel() {
  const { solid } = useNovaIcons();
  return (
    <span>
      <solid.ArrowPathIcon className="h-4 w-4" aria-hidden /> Retry
    </span>
  );
}
```
