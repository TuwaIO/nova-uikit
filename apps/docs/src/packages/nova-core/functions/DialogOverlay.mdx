# DialogOverlay()

> **DialogOverlay**(`props`): `Element`

Defined in: [components/Modal.tsx:63](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-core/src/components/Modal.tsx#L63)

The dimmed, blurred backdrop behind the dialog, faded in and out with `framer-motion`. [DialogContent](?path=/docs/packages-nova-core-variables-dialogcontent--docs) renders
it.

Side effect: while it is mounted, the page does not scroll (`lockPageScroll`).

## Parameters

### props

The overlay props.

#### backdropAnimation?

`Variants`

`framer-motion` variants (`initial`, `animate`, `exit`) of the backdrop; a fade by
default.

#### className?

`string`

Classes added to the backdrop element.

## Returns

`Element`

The backdrop.
