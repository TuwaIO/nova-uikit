# DialogOverlay()

> **DialogOverlay**(`props`): `Element`

Defined in: [components/Modal.tsx:79](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-core/src/components/Modal.tsx#L79)

The dimmed backdrop behind the dialog (ink at 50%, no blur), faded in with `framer-motion` (Radix removes it at once on close, so an
`exit` variant does not run). [DialogContent](?path=/docs/packages-nova-core-variables-dialogcontent--docs) renders
it.

Side effect: while it is mounted, the page does not scroll (`lockPageScroll`).

## Parameters

### props

The overlay props.

#### backdropAnimation?

`Variants`

`framer-motion` variants (`initial`, `animate`, `exit`) of the backdrop; a fade by
default.

#### className?

`string`

Classes added to the backdrop element.

## Returns

`Element`

The backdrop.
