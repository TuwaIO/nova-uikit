# NetworkIcon()

> **NetworkIcon**(`props`): `Element`

Defined in: [components/NetworkIcon.tsx:40](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-core/src/components/NetworkIcon.tsx#L40)

The icon of a network. Networks listed in `@web3icons/common` are drawn with `@web3icons/react`, loaded on demand one
icon at a time (a pulsing [FallbackIcon](?path=/docs/packages-nova-core-functions-fallbackicon--docs) is shown meanwhile) and rendered through [SvgToImg](?path=/docs/packages-nova-core-functions-svgtoimg--docs). An unknown numeric chain
shows a `?` placeholder; an unknown string id is fetched from the web3icons repository on GitHub
([GithubFallbackIcon](?path=/docs/packages-nova-core-functions-githubfallbackicon--docs)). Testnets and the Solana devnet and testnet are recolored with `--tuwa-testnet-icons`.

Side effect: a GitHub request (`raw.githubusercontent.com`) for icons that `@web3icons/common` does not list.
