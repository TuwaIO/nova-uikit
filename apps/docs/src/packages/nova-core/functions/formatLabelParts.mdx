# formatLabelParts()

> **formatLabelParts**\<`T`\>(`label`, `values`): (`string` \| `T`)[]

Defined in: utils/formatLabel.ts:24

Splits a label at its `{name}` placeholders and puts the values in their place, for values that are not text, such
as links. Unknown placeholders stay as they are.

## Type Parameters

### T

`T`

Type of the values.

## Parameters

### label

`string`

A label with placeholders, for example `You agree to the {terms}.`.

### values

`Record`\<`string`, `T`\>

The value of each placeholder.

## Returns

(`string` \| `T`)[]

The text parts and the values, in order (empty texts left out).
