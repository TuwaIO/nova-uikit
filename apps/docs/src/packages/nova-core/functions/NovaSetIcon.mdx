# NovaSetIcon()

> **NovaSetIcon**(`props`): `Element`

Defined in: [components/NovaSetIcon.tsx:41](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-core/src/components/NovaSetIcon.tsx#L41)

Draws an icon of the icon set of the closest `NovaIconsProvider` (the pixel icons of `@tuwaio/nova-icons` without one).
The Nova components draw their icons through it, so that one set changes all of them.

## Parameters

### props

[`NovaSetIconProps`](?path=/docs/packages-nova-core-type-aliases-novaseticonprops--docs)

See [NovaSetIconProps](?path=/docs/packages-nova-core-type-aliases-novaseticonprops--docs).

## Returns

`Element`

The icon.

## Example

```tsx
import { NovaSetIcon } from '@tuwaio/nova-core';

export function RetryLabel() {
  return (
    <span>
      <NovaSetIcon solid="ArrowPathIcon" className="h-4 w-4" aria-hidden /> Retry
    </span>
  );
}
```
