# TokenIcon()

> **TokenIcon**(`props`): `Element`

Defined in: [components/TokenIcon.tsx:27](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-core/src/components/TokenIcon.tsx#L27)

The icon of a token by its symbol, drawn with `@web3icons/react` and loaded on demand one icon at a time (a pulsing
[FallbackIcon](?path=/docs/packages-nova-core-functions-fallbackicon--docs) meanwhile), without the token list of `@web3icons/common`. Icons exist for the tokens of the icon
map (the tokens of networks and of Payments: USDC, USDT, EURC, PYUSD, DAI, GHO, ETH, POL, BNB, SOL); any other
token shows the first letter of its symbol.
