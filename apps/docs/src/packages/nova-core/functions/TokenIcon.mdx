# TokenIcon()

> **TokenIcon**(`props`): `Element`

Defined in: [components/TokenIcon.tsx:26](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-core/src/components/TokenIcon.tsx#L26)

The icon of a token by its symbol, drawn with `@web3icons/react` and loaded on demand one icon at a time (a pulsing
[FallbackIcon](?path=/docs/packages-nova-core-functions-fallbackicon--docs) meanwhile), without the token list of `@web3icons/common`. Icons exist for 123 tokens: the tokens of Payments
and the popular ones (`web3IconImports`). Any other token shows the first letter of its symbol.
