# useMediaQuery()

> **useMediaQuery**(`query`): `boolean`

Defined in: [hooks/useMediaQuery.ts:11](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-core/src/hooks/useMediaQuery.ts#L11)

A custom hook to detect if a media query matches. Returns `false` on the server and during hydration, so the first
render in the browser matches the markup of the server. In the browser it follows the `change` event of the query,
through a listener that is removed on unmount.

## Parameters

### query

`string`

The media query string (e.g., '(max-width: 767px)').

## Returns

`boolean`

Whether the query matches.
