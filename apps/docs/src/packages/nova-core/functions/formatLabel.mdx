# formatLabel()

> **formatLabel**(`label`, `values`): `string`

Defined in: utils/formatLabel.ts:8

Replaces the `{name}` placeholders of a label with values; unknown placeholders are kept.

## Parameters

### label

`string`

A label with placeholders, for example `Step {current} of {total}`.

### values

`Record`\<`string`, `string` \| `number`\>

The value of each placeholder.

## Returns

`string`

The label with the values.
