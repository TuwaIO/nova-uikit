# StatusTone

> **StatusTone** = `"pending"` \| `"success"` \| `"error"` \| `"neutral"` \| `"warning"`

Defined in: [components/StatusEdge.tsx:15](https://github.com/TuwaIO/nova-uikit/blob/main/packages/nova-core/src/components/StatusEdge.tsx#L15)

The state a [StatusEdge](?path=/docs/packages-nova-core-functions-statusedge--docs) shows. `neutral` is a result that is neither a success nor an error. `warning` has the color of
`pending` and stands still: something needs a person's attention, and a running glint would say that work goes on by itself.
