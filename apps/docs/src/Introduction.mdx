**A comprehensive design system and component library for building modern, robust, and beautiful Web3 applications.**

Welcome to the Storybook for **Nova UI Kit**, developed by **TUWA**. Nova UI Kit is the complete **View Layer** for multi-chain React dApps in the TUWA ecosystem. It is built directly on top of **[Orbit Utils](https://github.com/TuwaIO/orbit)** (L1/L2), **[Satellite Connect](https://github.com/TuwaIO/satellite-connect)** (L3/L4), and **[Pulsar Engine](https://github.com/TuwaIO/pulsar-core)** (L3/L4), abstracting away the complexity of wallet connections and transaction tracking into beautiful, accessible React components.

Nova UI Kit resides at the top of the integration stack, representing **UI Core (L6)** and **UI Components (L7)** of the TUWA Ecosystem.

---

## Why Nova UI Kit?

Building decentralized applications (dApps) requires managing complex visual states: wallet selections, active connection balances, network switching alerts, and background transaction finality indicators.

Nova UI Kit solves this by:

1. **Unifying Styling Tokens (L6):** `@tuwaio/nova-core` provides consistent theming variables, font properties, and dialog overlays.
2. **Providing Ready-made Components (L7):** `@tuwaio/nova-connect` handles wallet connection flows, while `@tuwaio/nova-transactions` visualizes transaction lifecycles.
3. **Decoupled Architecture:** Components auto-react to headless state changes from Satellite and Pulsar stores, eliminating duplicate local state tracking.
4. **Ensuring Accessibility:** Dialog and selection components are built on Radix UI primitives with full ARIA keyboard navigation compliance.

---

## ✨ Key Features

- **Unified Multi-Chain UI:** Single component library compatible with both EVM (injected wallets, WalletConnect) and Solana (Phantom, Solflare) standard providers.
- **Modern React Framework:** Built strictly using React 19+, TypeScript 6.0+, and Tailwind CSS v4.
- **Dynamic Theming:** Control design primitives globally through `--tuwa-*` CSS custom properties.
- **Decoupled Logic:** Zero hardcoded business logic. Visual components react directly to headless stores.
- **Accessible by Default:** Focus-trapping modals, aria attributes, and keyboard controls.
- **Internationalization:** Custom localization engine for text label overrides.

## Getting Started

Follow these steps to set up Nova UI Kit in a multi-chain React or Next.js application.

### Step 1: Install Dependencies

Install the core TUWA integration modules along with their required peer dependencies:

```bash
# 1. TUWA Ecosystem Packages
pnpm add @tuwaio/orbit-core @tuwaio/orbit-evm @tuwaio/orbit-solana \
         @tuwaio/satellite-core @tuwaio/satellite-evm @tuwaio/satellite-solana @tuwaio/satellite-react \
         @tuwaio/pulsar-core @tuwaio/pulsar-evm @tuwaio/pulsar-solana @tuwaio/pulsar-react \
         @tuwaio/nova-core @tuwaio/nova-connect @tuwaio/nova-transactions

# 2. State & Utilities
pnpm add zustand immer dayjs clsx tailwind-merge

# 3. Web3 Primitives
pnpm add viem wagmi @wagmi/core @tanstack/react-query gill @wallet-standard/react

# 4. Layout & Animations
pnpm add framer-motion @emotion/is-prop-valid \
         @radix-ui/react-dialog @radix-ui/react-select \
         @heroicons/react @web3icons/react @web3icons/common \
         ethereum-blockies-base64 react-toastify
```

### Step 2: Configure CSS with Tailwind v4

Import Nova's CSS variables and primitives inside your main application stylesheet:

```css
/* src/styles/app.css */

/* 1. Import Nova Core Design Tokens (L6 - REQUIRED) */
@import '@tuwaio/nova-core/dist/index.css';

/* 2. Import Nova Component Layouts (L7) */
@import '@tuwaio/nova-connect/dist/index.css';
@import '@tuwaio/nova-transactions/dist/index.css';

/* 3. Import Tailwind CSS */
@import 'tailwindcss';
```

### Step 3: Setup Web3 and Chain Parameters

Define your supported EVM chains, RPC nodes, and Wagmi configs:

```tsx
// src/config/appConfig.ts
import { createConfig } from '@wagmi/core';
import { injected } from '@wagmi/connectors';
import { mainnet, sepolia } from 'viem/chains';
import type { Chain } from 'viem/chains';
import { createDefaultTransports } from '@tuwaio/satellite-evm';

export const appEVMChains = [mainnet, sepolia] as readonly [Chain, ...Chain[]];

export const solanaRPCUrls = {
  devnet: 'https://api.devnet.solana.com',
};

export const wagmiConfig = createConfig({
  connectors: [injected()],
  transports: createDefaultTransports(appEVMChains),
  chains: appEVMChains,
  ssr: true,
});
```

### Step 4: Create the Transaction Store (Pulsar)

Configure the persistent background transaction tracking engine with EVM and Solana adapters:

```tsx
// src/hooks/usePulsarStore.ts
'use client';

import { createBoundedUseStore, createPulsarStore, Transaction } from '@tuwaio/pulsar-core';
import { pulsarEvmAdapter } from '@tuwaio/pulsar-evm';
import { pulsarSolanaAdapter } from '@tuwaio/pulsar-solana';
import { wagmiConfig, appEVMChains, solanaRPCUrls } from '@/config/appConfig';

const storageName = 'transactions-tracking-storage';

export enum TxType {
  swap = 'swap',
}

type SwapTx = Transaction & {
  type: TxType.swap;
  payload: { fromToken: string; toToken: string; amount: string };
};

export type TransactionUnion = SwapTx;

export const usePulsarStore = createBoundedUseStore(
  createPulsarStore<TransactionUnion>({
    name: storageName,
    adapter: [pulsarEvmAdapter(wagmiConfig, appEVMChains), pulsarSolanaAdapter({ rpcUrls: solanaRPCUrls })],
    maxTransactions: 50, // FIFO Policy to prevent storage bloat
  }),
);
```

### Step 5: Configure Global Providers

Wrap your React tree. The providers must be layered to allow visual elements (Nova) to resolve states from logical engines (Satellite, Pulsar):

```tsx
// src/providers/Web3Providers.tsx
'use client';

import { ReactNode } from 'react';
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
import { WagmiProvider } from 'wagmi';
import { satelliteEVMAdapter } from '@tuwaio/satellite-evm';
import { satelliteSolanaAdapter } from '@tuwaio/satellite-solana';
import { SatelliteConnectProvider, useSatelliteConnectStore } from '@tuwaio/nova-connect/satellite';
import { EVMConnectorsWatcher } from '@tuwaio/nova-connect/evm';
import { SolanaConnectorsWatcher } from '@tuwaio/nova-connect/solana';
import { NovaConnectProvider } from '@tuwaio/nova-connect';
import { NovaTransactionsProvider } from '@tuwaio/nova-transactions/providers';
import { getAdapterFromConnectorType } from '@tuwaio/orbit-core';
import { useInitializeTransactionsPool } from '@tuwaio/pulsar-react';

import { wagmiConfig, appEVMChains, solanaRPCUrls } from '@/config/appConfig';
import { usePulsarStore } from '@/hooks/usePulsarStore';

const queryClient = new QueryClient();

// Connects headless Pulsar state to Nova Transactions UI
function NovaTransactionsWrapper() {
  const getAdapter = usePulsarStore((state) => state.getAdapter);
  const initialTx = usePulsarStore((state) => state.initialTx);
  const closeTxTrackedModal = usePulsarStore((state) => state.closeTxTrackedModal);
  const transactionsPool = usePulsarStore((state) => state.transactionsPool);
  const executeTxAction = usePulsarStore((state) => state.executeTxAction);
  const initializeTransactionsPool = usePulsarStore((state) => state.initializeTransactionsPool);

  const activeConnection = useSatelliteConnectStore((state) => state.activeConnection);

  // Restart tracking on client reload if there are pending transactions
  useInitializeTransactionsPool({ initializeTransactionsPool });

  return (
    <NovaTransactionsProvider
      transactionsPool={transactionsPool}
      initialTx={initialTx}
      closeTxTrackedModal={closeTxTrackedModal}
      executeTxAction={executeTxAction}
      connectedWalletAddress={activeConnection?.isConnected ? activeConnection.address : undefined}
      connectedAdapterType={getAdapterFromConnectorType(activeConnection?.connectorType ?? 'evm:')}
      adapter={getAdapter()}
    />
  );
}

export function Web3Providers({ children }: { children: ReactNode }) {
  return (
    <WagmiProvider config={wagmiConfig}>
      <QueryClientProvider client={queryClient}>
        <SatelliteConnectProvider
          adapter={[satelliteEVMAdapter(wagmiConfig, appEVMChains), satelliteSolanaAdapter({ rpcUrls: solanaRPCUrls })]}
          autoConnect={true}
        >
          {/* Synchronize raw connector events with the store */}
          <EVMConnectorsWatcher wagmiConfig={wagmiConfig} />
          <SolanaConnectorsWatcher />

          <NovaConnectProvider
            appChains={appEVMChains}
            solanaRPCUrls={solanaRPCUrls}
            withBalance
            withChain
            withImpersonated
          >
            <NovaTransactionsWrapper />
            {children}
          </NovaConnectProvider>
        </SatelliteConnectProvider>
      </QueryClientProvider>
    </WagmiProvider>
  );
}
```

### Step 6: Dispatching Tracked Actions in Components

Trigger Web3 transactions using `executeTxAction`. The overlay modals and toast progress feeds will launch automatically:

```tsx
// src/components/SwapWidget.tsx
import { sepolia } from 'viem/chains';
import { OrbitAdapter } from '@tuwaio/orbit-core';
import { ConnectButton } from '@tuwaio/nova-connect/components';
import { useSatelliteConnectStore } from '@tuwaio/nova-connect/satellite';
import { TxActionButton } from '@tuwaio/nova-transactions/components';
import { usePulsarStore, TxType } from '@/hooks/usePulsarStore';

export function SwapWidget() {
  const executeTxAction = usePulsarStore((state) => state.executeTxAction);
  const transactionsPool = usePulsarStore((state) => state.transactionsPool);
  const getLastTxKey = usePulsarStore((state) => state.getLastTxKey);

  const activeConnection = useSatelliteConnectStore((state) => state.activeConnection);

  const triggerSwap = async () => {
    // 1. Define the logic closure returning a transaction hash (0x...)
    const writeSwap = async () => {
      // Contract write execution logic
      return '0x...';
    };

    // 2. Invoke the lifecycle monitor
    await executeTxAction({
      actionFunction: writeSwap,
      onSuccess: (tx) => console.log('Swap completed successfully!', tx.hash),
      params: {
        type: TxType.swap,
        adapter: OrbitAdapter.EVM,
        desiredChainID: sepolia.id, // Switches network if active wallet is on wrong chain
        title: 'Swap ETH',
        description: 'Swapping 1 ETH for USDT',
        payload: { fromToken: 'ETH', toToken: 'USDT', amount: '1' },
        withTrackedModal: true, // Opens the Nova modal automatically
      },
    });
  };

  return (
    <div className="flex flex-col items-center gap-4 p-8 border border-[var(--tuwa-border-primary)] rounded-[var(--tuwa-rounded-corners)]">
      <ConnectButton />
      <TxActionButton
        action={triggerSwap}
        getLastTxKey={getLastTxKey}
        transactionsPool={transactionsPool}
        walletAddress={activeConnection?.isConnected ? activeConnection.address : undefined}
        className="px-6 py-2 bg-[var(--tuwa-text-accent)] text-[var(--tuwa-text-on-accent)] font-medium"
      >
        Execute Swap
      </TxActionButton>
    </div>
  );
}
```

## Theme & Customization

All colors, borders, and rounded sizes are customizable globally by overwriting CSS Custom Properties in your main stylesheet:

```css
/* src/styles/app.css */
:root {
  --tuwa-text-accent: #6366f1; /* Indigo-500 */
  --tuwa-text-on-accent: #ffffff;
  --tuwa-bg-primary: #ffffff;
  --tuwa-bg-secondary: #f9fafb;
  --tuwa-rounded-corners: 6px;
}

/* Dark mode overrides (automatically toggled on .dark class) */
.dark {
  --tuwa-bg-primary: #0f172a;
  --tuwa-bg-secondary: #1e293b;
  --tuwa-text-primary: #f1f5f9;
  --tuwa-border-primary: #334155;
}
```

Refer to the **[Theming & Customization Guide](./Theming)** to explore deep component customization props and the shared styles pattern.
