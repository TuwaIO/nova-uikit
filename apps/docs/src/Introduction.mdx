**Nova UI Kit** is the user interface project of TUWA Stage 4: React components for wallet connections and transactions on EVM and Solana. It renders the state of Satellite Connect (connect button, connect and connected modals, chain selector) and of Pulsar (transaction toasts, tracking modal, history), and signs users in with SIWX. The wallet and transaction state stays in those libraries; Nova keeps only UI state and ships compiled styles that you theme with CSS variables.

This Storybook is the documentation of Nova UI Kit: the **Packages** section documents every package and export, **Theming** describes the theme variables, and the other sections show the components with their customization options.

---

## 🏛️ Where Nova UI Kit Fits in TUWA

TUWA is built in stages. Each stage builds on the ones below it:

| Stage                          | Projects                                                                                                                  | Role                                                     |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| **1 — Core Auth & Primitives** | [SIWX](https://siwx.docs.tuwa.io/), [Orbit Utils](https://orbit.docs.tuwa.io/)                                            | CAIP-122 authentication and multi-chain primitives       |
| **2 — State & Connection**     | [Satellite Connect](https://satellite.docs.tuwa.io/), [Pulsar](https://pulsar.docs.tuwa.io/)                              | Wallet connection state machine and transaction tracking |
| **3 — Backend & Sync**         | [Quasar Cloud](https://docs.tuwa.io/quasar) or self-hosted [Quasar Community](https://github.com/TuwaIO/quasar-community) | Transaction indexing and cross-device sync               |
| **4 — User Interface**         | **Nova UI Kit**                                                                                                           | React design system and components                       |
| **5 — SDK Integration Layer**  | [TUWA SDK](https://sdk.docs.tuwa.io/)                                                                                     | One dependency that re-exports the stages above          |

Nova Connect renders the store of Satellite Connect and signs users in with SIWX, Nova Transactions renders the store of Pulsar (which can sync with Quasar), and both use Orbit Utils for chain helpers. Nova Transactions is optional: Nova Connect shows the transaction history only when you give it a Pulsar store.

## 🧭 Principles

1. **State lives outside the UI:** the wallets are in Satellite Connect, the transactions in Pulsar and the session in SIWX. Nova components only read that state and call its actions, so a custom UI can use the same stores next to Nova.
2. **One kit, many chains:** EVM and Solana wallets appear in the same connect modal, and the connected modal, the chain selector and the transaction views work for both.
3. **Themeable and replaceable:** every color, border and radius is a `--tuwa-*` CSS variable; most components take a `customization` prop with class name functions and replacement components for their parts, and every label can be overridden.
4. **Compiled styles, no conflicts:** each package ships its own stylesheet with prefixed Tailwind CSS v4 classes (`novacore:`, `novacon:`, `novatx:`), so it works with or without Tailwind CSS in your app.
5. **Accessible:** dialogs are built on Radix UI with focus management and keyboard support; buttons and lists carry ARIA labels.
6. **Transparent side effects:** the package pages list what is saved to `localStorage` and which hosts are contacted.

## 🔄 How the UI Works

```
Satellite Connect store (wallets)          Pulsar store (transactions)
  │ activeConnection, connections             │ transactionsPool, initialTx
  │ connectionError, switchNetworkError       │ executeTxAction
  ▼                                           ▼
NovaConnectProvider                         NovaTransactionsProvider
  │ ConnectButton, connect modal,             │ progress toasts, tracking modal,
  │ connected modal, chain selector,          │ transaction history, error toast
  │ error toasts, SIWX watcher                │
  ▼                                           ▼
user action (pick a wallet, switch chain,   user action (speed up, cancel, retry,
sign in, disconnect)                        open history)
  │                                           │
  └──► store action (connect, switchNetwork,  └──► adapter action (speedUpTxAction,
       disconnect) — the store changes and         cancelTxAction, retryTxAction) — the
       the components re-render                    store changes and the components re-render
```

## 💾 Installation

Install the packages and their peer dependencies as listed on the package pages: [`@tuwaio/nova-connect`](?path=/docs/packages-nova-connect-overview--docs) lists everything a wallet connection UI needs, [`@tuwaio/nova-transactions`](?path=/docs/packages-nova-transactions-overview--docs) the additions for transactions. Then import the stylesheets once in your app:

```css
@import '@tuwaio/nova-core/dist/index.css';
@import '@tuwaio/nova-connect/dist/index.css';
@import '@tuwaio/nova-transactions/dist/index.css';
```
