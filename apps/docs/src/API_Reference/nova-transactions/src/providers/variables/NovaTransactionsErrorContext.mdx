# NovaTransactionsErrorContext

> `const` **NovaTransactionsErrorContext**: `Context`\<[`NovaTransactionsErrorContextValue`](?path=/docs/api-reference-nova-transactions-src-providers-type-aliases-novatransactionserrorcontextvalue--docs)\>

Defined in: [packages/nova-transactions/src/providers/NovaTransactionsErrorContext.tsx:72](https://github.com/TuwaIO/nova-uikit/blob/122eda6c35fda42cb5ebbd4d22b52ca193d73789/packages/nova-transactions/src/providers/NovaTransactionsErrorContext.tsx#L72)

Internal context that forwards `customization` and the `enabled` flag from
`NovaTransactionsProvider` to any descendant component.

The default value keeps `enabled: true` and uses no customization, so
components rendered **outside** a `NovaTransactionsProvider` receive a
fully-functional hook with default styling.
