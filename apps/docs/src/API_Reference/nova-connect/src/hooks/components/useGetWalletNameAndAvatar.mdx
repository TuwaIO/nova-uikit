# useGetWalletNameAndAvatar()

> **useGetWalletNameAndAvatar**(`options`): [`WalletNameAndAvatarData`](?path=/docs/api-reference-nova-connect-src-hooks-interfaces-walletnameandavatardata--docs)

Defined in: [packages/nova-connect/src/hooks/useGetWalletNameAndAvatar.ts:71](https://github.com/TuwaIO/nova-uikit/blob/9f77db498ef8e33dee9b1f11d3ee15de6fa8bb48/packages/nova-connect/src/hooks/useGetWalletNameAndAvatar.ts#L71)

A custom hook to fetch the Name Service (e.g., ENS) name and avatar
for the currently active wallet.

This hook automatically detects the active wallet and its corresponding
adapter via the `useSatelliteConnectStore` and attempts to resolve the
wallet address to a human-readable name and avatar.

## Parameters

### options

`UseGetWalletNameAndAvatarOptions`

Configuration options for the hook

## Returns

[`WalletNameAndAvatarData`](?path=/docs/api-reference-nova-connect-src-hooks-interfaces-walletnameandavatardata--docs)

An object containing the resolved name, avatar, loading state, and utility functions

## Example

```typescript
import { useGetWalletNameAndAvatar } from './useGetWalletNameAndAvatar';

function DisplayWalletInfo() {
  const { ensName, ensAvatar, isLoading, ensNameAbbreviated, error, retry } = useGetWalletNameAndAvatar({
    abbreviateSymbols: 8,
    maxNameLength: 25
  });

  if (isLoading) {
    return <div>Resolving name...</div>;
  }

  if (error) {
    return <div>Error: {error} <button onClick={retry}>Retry</button></div>;
  }

  return (
    <div className="wallet-info">
      {ensAvatar && <img src={ensAvatar} alt="Wallet Avatar" />}
      <p title={ensName || ''}>{ensNameAbbreviated || 'No Name Found'}</p>
    </div>
  );
}
```
