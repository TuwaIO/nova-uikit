# isDefaultLabels()

> **isDefaultLabels**(`labels`): `boolean`

Defined in: [packages/nova-connect/src/hooks/useNovaConnectLabels.ts:186](https://github.com/TuwaIO/nova-uikit/blob/43c7a55d28279132af955bb9753b7b6a8415a597/packages/nova-connect/src/hooks/useNovaConnectLabels.ts#L186)

Utility function to check if labels are default ones (for external use)
This is a regular function, not a hook, so it can be used anywhere

## Parameters

### labels

`NovaConnectLabels`

The labels to check

## Returns

`boolean`

Whether the labels are the default English labels

## Example

```typescript
function SomeUtilityFunction(labels: NovaConnectLabels) {
  if (isDefaultLabels(labels)) {
    console.log('Using default English labels');
  }
}
```
