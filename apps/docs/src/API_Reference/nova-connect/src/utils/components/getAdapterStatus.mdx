# getAdapterStatus()

> **getAdapterStatus**(`type`): [`AdapterLoadStatus`](?path=/docs/api-reference-nova-connect-src-utils-type-aliases-adapterloadstatus--docs)

Defined in: [packages/nova-connect/src/utils/getChainsListByConnectorType.ts:518](https://github.com/TuwaIO/nova-uikit/blob/f0b142ef6afa957b11179d64f93d8572ba4f1839/packages/nova-connect/src/utils/getChainsListByConnectorType.ts#L518)

Gets the current loading status of a specific adapter.

Returns the current state of an adapter in the loading lifecycle. Useful
for UI indicators, debugging, or conditional logic based on adapter
availability.

## Parameters

### type

`OrbitAdapter`

The adapter type to check

## Returns

[`AdapterLoadStatus`](?path=/docs/api-reference-nova-connect-src-utils-type-aliases-adapterloadstatus--docs)

Current loading status of the adapter

## Example

```typescript
const evmStatus = getAdapterStatus(OrbitAdapter.EVM);

switch (evmStatus) {
  case 'idle':
    console.log('EVM adapter not yet requested');
    break;
  case 'loading':
    // Show loading spinner
    break;
  case 'loaded':
    // Enable EVM features
    break;
  case 'error':
    // Show fallback UI
    break;
}
```
