# 主题与定制指南

欢迎阅读 **Nova UI Kit** 的完整主题指南。本文档提供定制组件外观与行为所需的一切，帮助您与品牌风格完美契合。🎨

---

## 🎯 核心理念

Nova 的主题系统建立在三项基本原则之上：

1. **CSS 变量优先：** 所有样式均由 `--tuwa-*` CSS 自定义属性控制。只需覆盖一次，所有组件都会自动更新。
2. **集成 Tailwind CSS v4：** 直接将设计令牌用作任意值：`bg-[var(--tuwa-bg-primary)]`。
3. **分层定制：** 从简单的变量覆盖，到通过 `customization` 属性彻底重塑组件样式。

---

## 🚀 快速开始

### 第 1 步：配置 CSS 导入

```css
/* src/styles/app.css */

/* 1. Nova foundation (REQUIRED) */
@import '@tuwaio/nova-core/dist/index.css';

/* 2. Feature packages (as needed) */
@import '@tuwaio/nova-connect/dist/index.css';
@import '@tuwaio/nova-transactions/dist/index.css';

/* 3. Tailwind CSS */
@import 'tailwindcss';

/* 4. Your custom theme overrides */
:root {
  /* Override TUWA variables here */
}
```

## 🔧 进阶：通过属性定制组件

Nova 组件接受 `customization` 属性，可深度控制样式。这是全面改变视觉风格的推荐方式。

### 模式：共享样式对象

创建一个集中管理的样式文件，以确保风格一致：

```typescript
// utils/customization/shared_styles.ts
```

### 定制 Nova Connect

```typescript
// utils/customization/nova_connect_provider.ts
import { NovaConnectProviderCustomization } from '@tuwaio/nova-connect';
import { cn } from '@tuwaio/nova-core/utils';
import { SHARED_STYLES, BUTTON_STYLES } from './shared_styles';

export const nova_connect_customization: NovaConnectProviderCustomization = {
  modals: {
    connectModal: {
      classNames: {
        modalContainer: () => 'bg-[var(--tuwa-bg-secondary)]',
        header: () => cn('bg-[var(--tuwa-bg-secondary)]', 'border-b border-[var(--tuwa-border-primary)]'),
        title: () => cn(SHARED_STYLES.fontMonoMedium, SHARED_STYLES.textPrimary),
        closeButton: () =>
          cn(
            'cursor-pointer rounded-[4px] p-1 transition-colors',
            SHARED_STYLES.textSecondary,
            'hover:bg-[var(--tuwa-bg-muted)]',
            SHARED_STYLES.baseFocus,
          ),
        mainContent: () => 'bg-[var(--tuwa-bg-secondary)]',
        footer: () => cn('bg-[var(--tuwa-bg-secondary)]', 'border-t border-[var(--tuwa-border-primary)]'),
        backButton: () => BUTTON_STYLES.ghost,
        actionButton: () => BUTTON_STYLES.primary,
      },

      childComponents: {
        connectorsSelections: {
          connectorsBlock: {
            installed: {
              classNames: {
                title: () =>
                  cn(SHARED_STYLES.fontMonoMedium, SHARED_STYLES.textAccent, 'text-sm uppercase tracking-wide'),
              },
            },
          },
        },

        connecting: {
          classNames: {
            container: () => 'flex flex-col gap-4 items-center justify-center w-full',
            statusContainer: ({ statusData }) =>
              cn(
                'relative flex items-center justify-center',
                'min-w-[110px] min-h-[110px]',
                'border-2 rounded-full p-4',
                'transition-all duration-300 ease-in-out',
                statusData.state === 'error'
                  ? 'border-[var(--tuwa-error-icon)] bg-[var(--tuwa-error-icon)]/5'
                  : statusData.state === 'success'
                    ? 'border-[var(--tuwa-text-accent)] bg-[var(--tuwa-text-accent)]/5'
                    : 'border-[var(--tuwa-border-primary)] bg-[var(--tuwa-bg-secondary)]',
              ),
            spinner: () =>
              cn(
                'absolute animate-spin rounded-full -inset-[2px]',
                'border-2 border-[var(--tuwa-text-accent)] border-t-transparent',
              ),
          },
        },
      },
    },
  },
};
```

### 应用定制

```tsx
import { NovaConnectProvider } from '@tuwaio/nova-connect';
import { NovaTransactionsProvider, type NovaTransactionsProviderProps } from '@tuwaio/nova-transactions/providers';
import type { Transaction } from '@tuwaio/pulsar-core';
import type { ReactNode } from 'react';
import { mainnet } from 'viem/chains';

import { nova_connect_customization } from './utils/customization/nova_connect_provider';
import { nova_tx_customization } from './utils/customization/nova_tx_provider';

// The Pulsar store values and adapters, passed as in the README of @tuwaio/nova-transactions
type PulsarProps = Omit<NovaTransactionsProviderProps<Transaction>, 'customization'>;

// Rendered inside SatelliteConnectProvider, as in the README of @tuwaio/nova-connect
export function Providers({ children, pulsar }: { children: ReactNode; pulsar: PulsarProps }) {
  return (
    <NovaConnectProvider appChains={[mainnet]} customization={nova_connect_customization}>
      {children}
      <NovaTransactionsProvider {...pulsar} customization={nova_tx_customization} />
    </NovaConnectProvider>
  );
}
```
