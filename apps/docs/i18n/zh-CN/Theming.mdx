# 主题与定制指南

欢迎阅读 **Nova UI Kit** 的完整主题指南。本文档提供定制组件外观与行为所需的一切，帮助您与品牌风格完美契合。🎨

---

## 🎯 核心理念

Nova 的主题系统建立在三项基本原则之上：

1. **CSS 变量优先：** 所有样式均由 `--tuwa-*` CSS 自定义属性控制。只需覆盖一次，所有组件都会自动更新。
2. **集成 Tailwind CSS v4：** 直接将设计令牌用作任意值：`bg-[var(--tuwa-bg-primary)]`。
3. **分层定制：** 从简单的变量覆盖，到通过 `customization` 属性彻底重塑组件样式。

---

## 🚀 快速开始

### 第 1 步：配置 CSS 导入

```css
/* src/styles/app.css */

/* 1. Nova foundation (REQUIRED) */
@import '@tuwaio/nova-core/dist/index.css';

/* 2. Feature packages (as needed) */
@import '@tuwaio/nova-connect/dist/index.css';
@import '@tuwaio/nova-transactions/dist/index.css';

/* 3. Tailwind CSS */
@import 'tailwindcss';

/* 4. Your custom theme overrides */
:root {
  /* Override TUWA variables here */
}
```

## 🎨 完整设计令牌参考

### 浅色主题（默认）

```css
:root {
  /* Paper and ink: warm paper, ink text, lines of 1 px and the TUWA orange of the light theme, square, with no gradients
     or soft shadows. Primary, secondary and accent text hold WCAG AA (4.5:1) on the three surfaces; tertiary is for hints.
     The accent has two shades: a deep one for text and thin lines (`--tuwa-text-accent`, AA on paper) and a bright one
     for fills (the main button, lit pixels, illustrations), with ink on it. */
  --tuwa-success-bg: theme('colors.green.100');
  --tuwa-success-text: theme('colors.green.700');
  --tuwa-success-icon: theme('colors.green.500');

  --tuwa-error-bg: theme('colors.red.100');
  --tuwa-error-text: theme('colors.red.700');
  --tuwa-error-icon: theme('colors.red.500');

  --tuwa-pending-bg: theme('colors.yellow.100');
  --tuwa-pending-text: theme('colors.yellow.800');
  --tuwa-pending-icon: theme('colors.yellow.600');

  --tuwa-info-bg: #e9e8e4;
  --tuwa-info-text: #55545a;
  --tuwa-info-icon: #8e8e90;

  --tuwa-text-primary: #101014;
  --tuwa-text-secondary: #636366;
  --tuwa-text-tertiary: #8e8e90;
  --tuwa-text-accent: #b93b0a;
  --tuwa-text-on-accent: #101014;

  /* Raised (dialogs, cards), paper, sunken */
  --tuwa-bg-primary: #faf9f7;
  --tuwa-bg-secondary: #f2f1ee;
  --tuwa-bg-muted: #e9e8e4;

  --tuwa-border-primary: #d6d5d1;
  --tuwa-border-secondary: #e4e3df;
  /* The frame of a secondary button and of a chosen cell */
  --tuwa-border-strong: #a9a8a6;

  /* The main button is one solid color. It reads the gradient start, so a brand color set there before still applies;
     the gradient end only tints decorations (StarsBackground). */
  --tuwa-button-primary-bg: var(--tuwa-button-gradient-from);
  --tuwa-button-primary-bg-hover: var(--tuwa-button-gradient-from-hover);

  /* The TUWA orange: ink on it is 5.6:1, and it stands 3.2:1 apart from the raised paper (WCAG 1.4.11) */
  --tuwa-button-gradient-from: #f05a14;
  --tuwa-button-gradient-to: #ff8a5c;

  --tuwa-button-gradient-from-hover: #e34f0d;
  --tuwa-button-gradient-to-hover: #f05a14;

  /* The lit pixels of the icons and the accents of the illustrations and loaders: the bright fill of the brand, which a
     host that sets its brand color on the main button gets here too */
  --tuwa-icon-accent: var(--tuwa-button-primary-bg);

  /* A secondary button: no fill, a frame of `--tuwa-border-strong`, the hover fill */
  --tuwa-standart-button-bg: transparent;
  --tuwa-standart-button-hover: #e9e8e4;

  --tuwa-testnet-icons: #6b655e;

  /* Lines across a surface, a retro screen, barely there; `transparent` turns them off */
  --tuwa-scanline: rgb(16 16 20 / 0.015);

  /* The veil over the page behind an open dialog: dark enough that the page steps back and its text is not read
     through it */
  --tuwa-backdrop: rgb(16 16 20 / 0.68);

  --tuwa-rounded-corners: 0px;
  /* The shapes that were circles (avatars, icons of wallets, tokens and networks, dots): square; 9999px rounds them again */
  --tuwa-rounded-full: 0px;
  --tuwa-ring-width: 2px;
}
```

## ♿ 对比度 (WCAG 2.2 AA)

默认令牌在两种主题下都让文本保持 4.5:1 或更高的对比度（`nova-core` 会测试每一对）：`--tuwa-text-primary`、
`--tuwa-text-secondary` 和 `--tuwa-text-accent` 在所有背景上，`--tuwa-text-on-accent` 在主按钮上，
以及每种状态文本在其自身背景上。主按钮与页面的对比度为 3:1 或更高。以下规则可让您自己的组件保持易读：

- 仅将 `--tuwa-text-tertiary` 用于提示和装饰：其对比度低于 4.5:1。

修改令牌时，请使用 `@tuwaio/nova-core` 的 `contrastRatio` 检查您的配对。对于运行时选定颜色（商家的强调色）上的文本，
`readableTextColor(background)` 会返回白色或近黑色中更易读的一种。

## 🔧 进阶：通过属性定制组件

Nova 组件接受 `customization` 属性，可深度控制样式。这是全面改变视觉风格的推荐方式。

### 模式：共享样式对象

创建一个集中管理的样式文件，以确保风格一致。下面的示例是这些故事所用 Isometric 主题的一部分；[完整主题](https://github.com/TuwaIO/nova-uikit/blob/main/apps/docs/src/utils/customization/isometric.ts)涵盖每个部分：

```typescript
// customization/shared.ts
import { cn } from '@tuwaio/nova-core/utils';

// Set on every container: square corners and one typeface for all its parts
export const drawing = '**:rounded-none! **:font-sans!';

export const focus =
  'focus:outline-none focus-visible:ring-[length:var(--tuwa-ring-width)]! focus-visible:ring-offset-2 focus-visible:ring-[var(--tuwa-text-accent)]!';

export const text = {
  normal: 'font-normal',
  strong: 'font-semibold',
  primary: 'text-[var(--tuwa-text-primary)]!',
  secondary: 'text-[var(--tuwa-text-secondary)]!',
  onInk: 'text-[var(--tuwa-text-on-accent)]!',
};

export const surface = {
  base: 'bg-[var(--tuwa-bg-secondary)]!',
  ink: 'bg-[var(--tuwa-button-gradient-from)]!',
  border: 'border! border-[var(--tuwa-border-primary)]!',
};

const buttonBase = cn(
  'cursor-pointer inline-flex items-center justify-center gap-2 px-4 py-2 text-sm',
  surface.border,
  focus,
);

export const button = {
  primary: cn(buttonBase, text.strong, surface.ink, text.onInk),
  outline: cn(buttonBase, text.normal, surface.base, text.primary),
  // A square icon button on the ink bar of a header
  iconOnInk: cn(
    'cursor-pointer p-1 transition-colors bg-transparent! hover:bg-[var(--tuwa-bg-secondary)]!',
    text.onInk,
    'hover:text-[var(--tuwa-text-primary)]!',
  ),
};
```

### 定制 Nova Connect

```typescript
// customization/connect.ts
import type { NovaConnectProviderCustomization } from '@tuwaio/nova-connect';
import { cn } from '@tuwaio/nova-core/utils';

import { connectCard } from './connectCard';
import { button, drawing, surface, text } from './shared';

const sectionTitle = cn(text.strong, text.primary, 'text-xs uppercase tracking-wider');

export const connectCustomization: NovaConnectProviderCustomization = {
  modals: {
    connectModal: {
      classNames: {
        modalContainer: () => cn(drawing, surface.base),
        header: () => cn(surface.ink, text.onInk),
        title: () => cn(text.strong, text.onInk, 'text-base'),
        closeButton: () => button.iconOnInk,
        mainContent: () => surface.base,
        footer: () => surface.base,
        backButton: () => cn(button.outline, 'min-h-10'),
        actionButton: () => cn(button.primary, 'min-h-10'),
      },

      childComponents: {
        connectorsSelections: {
          connectorsBlock: {
            installed: { classNames: { title: () => sectionTitle }, connectCard },
            popular: { classNames: { title: () => sectionTitle }, connectCard },
          },
        },

        // The wallet in a frame that turns green or red; the message under it says the rest
        connecting: {
          classNames: {
            statusContainer: ({ statusData }) =>
              cn(
                'relative flex min-h-[150px] min-w-[150px] items-center justify-center border-2 p-6 transition-colors duration-300',
                surface.base,
                statusData.state === 'error'
                  ? 'border-[var(--tuwa-error-icon)]'
                  : statusData.state === 'success'
                    ? 'border-[var(--tuwa-success-icon)]'
                    : 'border-[var(--tuwa-border-secondary)]',
              ),
            statusMessage: () => cn(text.strong, text.primary, 'text-lg'),
          },
        },
      },
    },
  },
};
```

// customization/connectCard.ts
import type { ConnectCardCustomization } from '@tuwaio/nova-connect/components';
import { cn } from '@tuwaio/nova-core/utils';

import { focus, surface, text } from './shared';

export const connectCard: ConnectCardCustomization = {
  classNames: {
    container: ({ cardData }) =>
      cn(
        'group relative flex cursor-pointer items-center justify-between p-3',

        surface.border,
        'hover:bg-[var(--tuwa-bg-muted)]!',

    subtitle: () => cn(text.normal, text.secondary, 'text-xs'),

      cn(
        'h-5 w-5 -translate-x-2 opacity-0 transition duration-300 group-hover:translate-x-0 group-hover:opacity-100',
        text.primary,
      ),
  },
};

### 应用定制

```tsx
import { NovaConnectProvider } from '@tuwaio/nova-connect';
import { NovaTransactionsProvider, type NovaTransactionsProviderProps } from '@tuwaio/nova-transactions/providers';
import type { Transaction } from '@tuwaio/pulsar-core';
import type { ReactNode } from 'react';
import { mainnet } from 'viem/chains';

import { connectCustomization } from './customization/connect';
import { transactionsCustomization } from './customization/transactions';

// The Pulsar store values and adapters, passed as in the README of @tuwaio/nova-transactions
type PulsarProps = Omit<NovaTransactionsProviderProps<Transaction>, 'customization'>;

// Rendered inside SatelliteConnectProvider, as in the README of @tuwaio/nova-connect
export function Providers({ children, pulsar }: { children: ReactNode; pulsar: PulsarProps }) {
  return (
    <NovaConnectProvider appChains={[mainnet]} customization={connectCustomization}>
      {children}
      <NovaTransactionsProvider {...pulsar} customization={transactionsCustomization} />
    </NovaConnectProvider>
  );
}
```
